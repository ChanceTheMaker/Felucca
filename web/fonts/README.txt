Felucca SMK Studio display fonts

Source: https://fonts.google.com/ and https://github.com/google/fonts
Refreshed 2026-10-10 through the Google Fonts CSS API.
These subsets contain A-Z, a-z, digits and title punctuation (space, brackets,
ampersand, hyphen and period), including every glyph in Felucca SMK Studio and
Felucca [Salt] Studio. The former title-only subsets omitted M and K.
Use system fonts for other text.

Regenerate with: python tools/fetch_web_display_fonts.py
Requires fontTools for glyph validation. Update the fonts.css asset version
when replacing files so browsers discard the old subsets.

Font subsets retain their original family names and accompanying licenses.
Syncopate is Apache-2.0; the other families use the SIL Open Font License.
